# Kopi Senja Nusantara — Versi Pemula

## Isi folder
- `index.html` = isi dan struktur website.
- `style.css` = warna, ukuran, dan tata letak website.
- `images/` = tempat menyimpan foto.

## Cara menjalankan
1. Simpan semua file dalam satu folder.
2. Masukkan foto ke folder `images`.
3. Buka `index.html` di browser.

## Catatan untuk pemula
- HTML dipakai untuk membuat isi halaman.
- CSS dipakai untuk mengatur tampilan.
- `href="#menu"` membuat tautan menuju bagian dengan `id="menu"`.
- Formulir masih contoh dan belum menyimpan atau mengirim pesan.
